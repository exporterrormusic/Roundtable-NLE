  #40 │ —    │ GAUSSIAN BLUR BREAKS EXPORT COMPOSITING (GPU BARRIER)   │ ❌ TODO
      │ IMPACT: 2
      │ Gaussian Blur effect on ANY clip (not just nested) causes:
      │   • Layers above the blurred clip vanish or show inverted colors
      │   • Distortion and motion artifacts on nested sequences
      │   • Works correctly in Program Monitor, broken in export/export
      │     preview (only when forceFullResolution=true)
      │ Root cause: Render graph DAG declares per-effect output
      │ resources, but EffectProcessor writes to its own shared
      │ m_storageTextures[0/1]. Pipeline barriers are inserted for the
      │ declared DAG resources, NOT the actual EffectProcessor textures.
      │ GPU reads stale/corrupted data between effect and composite passes.
      │ Fix: Either make DAG aware of EffectProcessor's actual output
      │ textures, or have EffectProcessor use per-pass textures instead
      │ of shared ping-pong buffers. Needs Vulkan validation layer debug.
      │ Non-blur effects work because their kernels are smaller (less
      │ memory traffic → less likely to hit the barrier gap).
      │ FILES: src/gpu/CompositeEngine.cpp (compositeViaRenderGraph),
      │        src/gpu/EffectProcessor.cpp (process, outputDescriptorInfo)
