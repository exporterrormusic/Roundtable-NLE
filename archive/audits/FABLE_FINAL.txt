P1 — VERIFIED BUGS (found this session, code-confirmed, mostly small)
================================================================================
Graphics/captions cluster:
1. Drop Shadow initializer swaps distance/angle -> 135px shadow on enable.
   PropertiesPanel applyGfxShadowEnabled pushes {color,135,4,...} into
   ShadowEntry{color,distance,angle,...} (GraphicLayer.h:89-97). Fix the
   aggregate init; consider designated initializers for appearance structs.
2. SRT import/export bypasses the caption system entirely. exportSrt scans
   Graphic clips only (SrtIO.cpp:177-205) -> whisper-transcribed CaptionClips
   export "no subtitles"; importSrt creates Graphic clips instead of captions.
   Point both at captionTrack()/CaptionClips.
3. CaptionsPanel caches raw CaptionClip* (CaptionsPanel.h:125-129) and
   Timeline fires no clip-level notifications -> dangling pointers after
   timeline edits. Store IDs, resolve via findCaptionClipById (this is the
   established clip-lifetime pattern; TierList/Captions already fixed for
   Timeline*, this is the clip-level residue).
4. Inline-edit undo lambdas capture raw CaptionClip*/TextLayer*
   (OverlayController.cpp:883-884, 921-931). Sweep to the ID-capture pattern.
5. Export panel: "Broadcast 1080i" preset exists in the combo but applyPreset
   has no case for it (silently does nothing). Remove it or implement it.
6. Export panel: fps combo stores INTEGER rates for NTSC entries
   (23.976/29.97 -> 23/29?) — verify and fix rate plumbing end-to-end.
7. Export queue: "Remove from Queue" only deletes the QListWidget item — job/
   pipeline-slot state not cleaned. Also audit pipeline-slot reset after
   failed jobs and what guards timeline editing during an active export.

P3 — MEDIUM FEATURES (M/L effort, still workflow-relevant)
================================================================================
1. Burned-in caption styling: no outline/stroke (the standard way captions
   stay readable), bold is hard-coded, speaker labels never render
   (ClipRenderers.cpp:845 area). Needs a format bump — COORDINATE VERSIONS:
   masks took v30, Commentators plan reserves v31; caption fields ride
   whichever lands next, don't burn a third number.
2. Dead controls: Leading, baseline shift, stroke position (Center/Inner/
   Outer) are stored+serialized but ignored by buildTextPath
   (GraphicsEditorControls.cpp:324-339, 432-447). Wire them or hide them —
   silently-dead UI erodes trust in the whole panel.
3. Layer animation is model-complete (KeyframeTrack transforms evaluated
   per-tick) but unauthorable — every UI edit writes tick 0. Reuse the
   EffectControlsPanel stopwatch/keyframe UI for the focused layer's
   pos/scale/opacity. This is the gateway to animated titles.
4. TitleClip is creation-orphaned (only clone() constructs one) yet keeps a
   full UI/render/preset surface. Add load-time migration TitleClip ->
   GraphicClip(1 TextLayer), then delete the legacy surface.
5. Paragraph text box half-wired (useParagraphBox/boxWidth serialized, no UI,
   no wrap in renderer): finish word-wrap or rip the fields out.
