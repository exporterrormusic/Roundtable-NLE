WHAT MOVED WHERE

  • Icon rail + 5 sliding drawers → one persistent setup sidebar with the three pipeline steps (Script / Audio Files / Transcribe) always visible, numbered and check-marked as they complete. No panel animation, no hidden state.
  • MATCH drawer (character filter list) → filter chips above the cards, colored per character, with counts and the red UNMATCHED chip. Selecting a character still scopes Auto-Sync to it.
  • SETTINGS drawer (one checkbox) → gear popover on the action bar.
  • 4-modal export gauntlet → one Export dialog: show picker + sequence picker + missing-default-shot warning inline. Re-export stays one-click and prompt-free.
  • Dead UI dropped: the never-built transport bar and the permanently hidden orphan-clips list. Playback lives on the cards (Space / J-K-L), as it already does.
  • Everything on a card is unchanged: confidence bar, waveform with trim handles and non-destructive delete regions, Confirm / Play / Auto-trim / Reject, Reassign combo; unmatched lines keep Manual match, Assign-clip, and the audio-file pin.

LAYOUT LOGIC

The screen reads left-to-right as the pipeline: setup (script, files, transcription) → refine (script index + match cards) → ship (action bar with Export). The smart status line stays on top; the state language is the same everywhere — green confirmed, amber tentative, red unmatched — as a 3px stripe on both the index rows and the cards, so you can scan sync health at either zoom level.

The script index and cards stay scroll-synced: click a line on either side and the other follows. Session switching keeps per-script audio/clips/matches exactly as today.
