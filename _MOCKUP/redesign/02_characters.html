WHAT MOVED WHERE

  • 150px emoji sub-rail → top tab strip (LIBRARY · CUSTOM · CONVERT · COMPOSE). Frees ~130px of width for COMPOSE, and sub-navigation reads as tabs everywhere in the app.
  • SETTINGS stub page → gear button in the tab strip (popover). It was placeholder text; no page needed until it has content.
  • A–Z pop-out panel → slim always-visible letter index on the library list. No animation, one less moving part.
  • COMPOSE: SHOWS (180px) + CHARACTERS (220px) columns → one 212px browse column with SHOWS stacked above CHARACTERS. Same cascade filter, same counts, same context menus — half the width.
  • Faces row (4 stacked slots) → labeled 2×2 matrix (mouth × eyes) so the four states explain themselves.
  • CONVERT keeps its layout — summary card, encoder card, table, actions — restyled; status becomes pills with inline mini-progress. Cancel appears only while rendering.
  • All context menus unchanged: shot Duplicate/Rename/Move-to-Show/Delete; show Rename/Thumbnail; character alias Rename/Reset; asset Re-link/Reveal/Delete.

COMPOSE LAYOUT LOGIC

Left-to-right narrows from browsing to editing: browse (shows → characters) → shots (presets for that pick) → monitor + asset library (the work) → properties + layers (the detail). The monitor is the hero; direct-manipulation stays (drag to move, corner handles to scale, safe-margin toggle).

Properties panel keeps every field: transform (X/Y/scale/rotation/opacity/blur), flips, visibility, collapsible Crop; character rows adapt by type exactly as today — Spine gets Outfit/Stance/Anim, video characters get Outfit only when they have costumes, puppets get Outfit/Action. Background layers get transform + collapsible Video In/Out.

Premiere-style scrubbable blue values replace spin boxes — drag to scrub, click to type. Same ScrubbySpinBox behavior, quieter chrome.
