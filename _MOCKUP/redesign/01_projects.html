WHAT MOVED WHERE

  • Icon rail (NEW / OPEN / SAVE / IMPORT / SETTINGS) → header actions. Save stays global (Ctrl+S, File menu, title-bar saved state); Settings is the gear popover.
  • OPEN side panel → gone. The table is the project list; “Open…” browses for an external .rtp; recents live in File ▸ Recent Projects.
  • NEW side panel (5 step-cards) → one modal dialog, same fields: name, location + recent chips, aspect, resolution presets, fps, live summary.
  • Bottom action bar → double-click to open, right-click / “⋯” for everything else. No permanently-dimmed buttons on screen.
  • Emoji icons → 1.6px stroke line icons throughout.
  • New: grid view toggle, SHOW column + show filter, status-bar autosave indicator.
