A1 rationale:
  • Row height 32px (vs today's tall thumbnail rows) — ~2× the projects visible per screen.
  • Zebra striping + tabular numerics make resolution/fps/size columns instantly scannable.
  • Thumbnail shrinks to a 40×23 swatch (recognition without dominating). Toggle thumbnails off entirely via the column header context-menu — already supported today.
  • Footer collapses today's 4-button bank into a compact selection bar.
