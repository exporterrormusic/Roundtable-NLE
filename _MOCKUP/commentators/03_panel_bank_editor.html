Layout A — “Bank Editor.” The two banks physically flank the preview so the panel is a 1:1 spatial map of the final overlay: what you see on the left of the panel is what renders on the left of the program. Selecting any cell opens the inspector as a fourth flyout column (shown pre-selected on WELLS). The override lane docks under the preview so Set Start / Set End sit next to the picture they affect.

Pros vs 04 (Side Rail): spatial WYSIWYG bank placement; big preview stays centered and visible while editing either bank; overrides live directly under the playhead context. Cons vs 04: four columns get tight below ~1400 px dock width; the inspector flyout pushes content when it opens (or must overlay); it does not visually rhyme with the chosen Tier List panel, so users learn a second arrangement. See 04_panel_side_rail.html for the alternative.
