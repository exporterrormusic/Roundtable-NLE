Layout B — “Side Rail.” Mirrors the chosen Tier List panel (05_side_rail_final): live preview top-left, a bin-like editing surface under it (here the two banks as LEFT/RIGHT tabs with wide, path-showing cells), and a working rail on the right holding Setup (Populate + Recents), the box inspector, and the Overrides event list — the same place the Tier List keeps its EVENTS rail, so Set Start / Set End muscle memory transfers directly.

Pros vs 03 (Bank Editor): consistent with the Tier List panel the user already learned; inspector is always present (no flyout reflow); wide cells surface the portrait file path; scales down better since it is only two columns. Cons vs 03: only one bank visible at a time (tab flip to compare sides); the panel is not a spatial map of the overlay — you rely on the preview for left/right placement; the rail gets tall and scrolly on short docks. See 03_panel_bank_editor.html for the alternative.
