What changed vs. today & why:
  • Font sizes normalized — search 22px→13px, table data 22px→12.5px, rail icons 42px→21px. The current oversize type forces scrolling and reads as a kiosk; Premiere/Resolve run dense.
  • Rail slimmed 150px→76px with icon-over-label and an SVG-style accent state — reclaims ~75px of horizontal space for the list.
  • New "Show" column surfaces the existing per-project show assignment (today it's buried in a right-click submenu).
  • Hover row-actions (duplicate / rename / delete) + a selection-aware footer replace the always-on bottom button bank — same actions, less chrome.
  • List/Grid toggle lets the same panel host Design B without a separate mode.
Design B Gallery Grid Thumbnail-first, like DaVinci Resolve's Project Manager. Best when projects are visually distinct. Cards carry res/fps chips, current-project flag, and hover quick-actions; an inline "New" tile.

Why a grid:
  • Thumbnails are first-class — you already auto-capture a viewport grab on save (setThumbnailFromImage); a grid finally pays that off. A user recognizes a project by its picture faster than by a filename row.
  • Resolution / fps / show / current-flag all live on the card — every column from today's table is represented, nothing lost.
  • Thumbnail size slider (− ／ ＋) scales cards; same control DaVinci uses. Lazy-load thumbnails (only decode cards in/near viewport) to keep large libraries snappy.
  • Inline "New" tile is a faster on-ramp than hunting the rail.

Why a hub:
  • Resume in one click — the Recent rail mirrors your existing setRecentProjects() list; most sessions start by reopening the last project, so it's front-and-center.
  • The 3 primary actions are explicit buttons, not icon-rail glyphs — discoverable for new users, and the "New Project" button can carry last-used defaults.
  • Show chips turn the per-project show metadata into a one-click filter (cascading like COMPOSE's SHOWS column).
  • Save / Settings / Import still reachable: Import & New & Open in the header, Settings via the location panel's gear, Save is a no-op here (handled globally / Ctrl+S).
  • Trade-off: the icon rail is gone, so this is the biggest departure from today's structure.
